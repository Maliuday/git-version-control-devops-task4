# Git Version Control DevOps Project

## Project Overview
This project demonstrates Git and GitHub version control best practices through a practical DevOps workflow.

## Objective
To manage a project using Git, GitHub, branching strategies, commits, pull requests, merge conflict resolution, tags, and documentation.

## Tools Used
- Git
- GitHub
- Visual Studio Code

## Branching Strategy

This project follows a simple Git branching workflow:

- `main` – Stable and final version
- `dev` – Development and integration branch
- `feature/docs` – Feature branch for documentation updates

## Tasks Implemented

1. Initialized and cloned a Git repository.
2. Configured Git username and email.
3. Created development and feature branches.
4. Practiced staging and committing changes.
5. Used Pull Requests to merge feature branches.
6. Practiced merge conflict resolution.
7. Configured `.gitignore`.
8. Created and pushed Git tags.
9. Documented Git commands and interview questions.
